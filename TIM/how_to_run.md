# TIM - Como rodar

## Requisitos

```bash
python -m pip install -r requirements.txt
```

## Execução principal

Na pasta TIM:

```bash
python tim_lojas_scrapper.py
```

Esse scraper coleta dados da TIM e salva o resultado em JSON.

## Saída gerada

- tim_lojas.json

## Observações

- O fluxo TIM atual é um scraper direto, sem etapa de formatador/Excel.
- O script foi validado em execução real.
- O arquivo final fica na pasta TIM.
